# Lexik — pages publiques

Pages légales de l'application Android Lexik (`com.beginz.lexik`), servies par GitHub Pages :

- `privacy/` — politique de confidentialité en anglais, la version par défaut
- `confidentialite/` — la même politique en français, à tenir alignée sur la version anglaise

Depuis l'app, `privacy/?lang=fr` ou `privacy/?lang=en` ouvre directement la bonne langue. `confidentialite/` reste en français sans argument : c'est l'adresse des versions déjà installées.

Lexik n'a ni compte ni serveur : il n'y a pas de page de suppression de compte.
Ce dépôt est la seule source de ces pages.
